## How to Capture Real Screenshots

1. Launch ContrastCraft:
   ```cmd
   run.bat
   ```
2. Navigate to `http://127.0.0.1:8000`.
3. Click **"📁 Load Sample Showcase"** and **"⚡ Run Contrast Audit"**.
4. Use Windows Snipping Tool (`Win + Shift + S`) to capture each view.
5. Save the images into this directory (`screenshots/`) matching the filenames above.
